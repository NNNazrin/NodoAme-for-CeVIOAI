# cevio-NodoAme-talk 人话版使用指南

> 一句话：**输入一段日文，它就用 VOICEVOX 说出这段话，再让 CeVIO AI 的歌声库把它唱成 WAV 文件。**

这份文档不需要你懂任何技术名词，照做即可。技术细节在另一份 `cevio-NodoAme-talk.md` 里。

---

## 一、第一次打开

1. 双击 `cevio-NodoAme-talk.exe`；
2. 如果你是第一次运行，它会依次问你几个问题，**每个问题直接回车就是推荐值**：
   - CeVIO AI 装在哪（会**自动从注册表探测**；探测不到会给一个示例路径，直接回车即可）
   - 用哪个歌声库（自动取注册表里已安装的第一个；之后随时用 `/voices` 换）
   - 这个歌声库叫什么名字（决定文件名前缀，可自取，例如「我的声库」）
   - 词典目录、输出目录、中间目录（都直接回车）
3. 最后它打印一行字，中间写着 `[ok]` 的都是正常的。

**注意：** 第一次运行需要 VOICEVOX 在后台开着（`http://127.0.0.1:50021`），否则会提示 Talk 引擎连不上。

---

## 二、说一句话

打开后你会看到一行：

```
cevio-NodoAme-talk <版本>  |  Talk.Engine: VOICEVOX  |  Talk: <Talk角色>  |  Output.Engine: CeVIO AI  |  Output: <声库名>
>
```

这行字在告诉你：**现在谁在说（Talk）** 和 **谁在唱（Output）**。

在 `>` 后面**直接输入日文**，回车：

```
> こんにちは、私はせかいです
ccst  ok  (13854 B)  3.3s          ← 第 1 步：文字变乐谱
wav   ok  (460844 B)  3.9s          ← 第 2 步：乐谱变歌
out   : ...\output\<声库名>-こんにちは-1.03s.wav
time  : 7.23s, trimmed 181088 samples
```

生成的 WAV 在 `output` 文件夹里，文件名是 **`声库名-前5个字-时长`**，一眼就能认出是谁唱的、多长。

**输入文字时不要加 `/`。** 加了 `/` 的是命令，见下面。

---

## 三、换一个歌声库（Output）

> **打字小技巧**：按 **Tab** 会自动补全；**空着直接按 Tab** 会把所有命令和用途列出来；**↑ / ↓** 翻之前输入过的内容；**Esc** 清空当前这一行。

先看有哪些：

```
> /voices
声库来源: registry  (CeVIO 安装注册表)
   1.   声库甲  [CSNV-XXX-AAA]  1.0.0  <模型文件名>.tsnvoice
   2. * 声库乙  [CSNV-XXX-BBB]  1.0.2  <模型文件名>.tsnvoice
```

`*` 是当前正在用的。切换：

```
> /use 1 --as 我的声库
已切换输出声库: 我的声库  [CSNV-XXX-BBB]  <模型文件名>.tsnvoice
cevio-NodoAme-talk 1.2.1  | ... | Output: <声库名>        ← 这行会立刻刷新
```

- `--as 名字` 是**给这个声库起个显示名**（决定文件名前缀）。不起名的话就用注册表里的产品名（注册表里的产品名）。
- 也可以直接写名字或 CastId：`/use 1`、`/use 我的声库`、`/use CSNV-XXX-BBB`，支持只写一半。

**想用自己起的名字管理声库？** 打开 `json` 模式：

```
/config set output.voiceSource=json
/voices --dump          ← 按注册表生成一份 voices.json，可以随便改 name
/voices                 ← 之后列表就来自这个文件
```

`voices.json` 就在工具目录下，用记事本改 `name` 即可。

## 四、换说话的角色（Talk）

说话的角色由 VOICEVOX 决定，用数字编号切换：

```
> /config set talk.speaker=1
已更新 1 项
cevio-NodoAme-talk 1.2.1  | ... | Talk: <Talk角色> | ...   ← 立刻刷新
```

常用编号（本机 VOICEVOX 0.25.2）：

| 编号 | 角色 |
|---|---|
| 1 | <角色A> |
| 2 | <角色B> |
| 3 | <角色C> |

具体有哪些角色、每个角色的编号，以 `http://127.0.0.1:50021/speakers` 里 `styles[].id` 为准。

编号可以自己查：浏览器打开 `http://127.0.0.1:50021/speakers`，每个角色下面 `styles` 里的 `id` 就是编号。

## 五、播放

| 想做什么 | 怎么做 |
|---|---|
| 播放刚生成的那个 | `/playlast`（也可以 `/play`、`/replay`） |
| 播放指定文件 | `/play D:\某个\文件.wav` |
| 每次自动播放 | `/config set switch.autoPlayOnRender=true`（默认关），关掉用 `false` |

## 六、常用命令速查

| 命令 | 作用 |
|---|---|
| 直接输入文字（无 `/`） | 合成 WAV |
| `/say 文字` | 同上（带参数时用这个，如 `/say 文字 --no-trim`） |
| `/voices` | 列出所有歌声库 |
| `/use 编号\|名字 --as 显示名` | 换歌声库 |
| `/playlast` | 播放刚生成的 WAV |
| `/config set 键=值` | 改设置（`/config show` 看全部） |
| `/doctor` | 体检：检查声库、词典、VOICEVOX 是否都在 |
| `/runs` | 看最近几次运行的记录 |
| `/clean` | 清理旧记录（默认只留最近 5 次） |
| `/help` | 命令列表 |
| `/exit` | 退出 |

**文件都放哪：**

- `output\` —— 生成的 WAV，永久保留；
- `runs\` —— 每次运行的乐谱和日志，只保留最近 5 次；
- `tmp\` —— 临时文件，每轮自动清空。

## 七、遇到问题

**输入日文变成问号 / 生成的文件是空的**
→ 确认是在**双击打开的那个窗口**里输入（不要用管道或别的程序转发）。如果还是不行，把日文写进一个 UTF-8 的 txt，用 `/say --file 文件路径` 传入。

**提示 `文本没有可唱音节 (notes=0)`**
→ 这段文字没有可发音的内容（例如全是符号）。换正常日文句子。

**提示 `empty audio (peak=0)`**
→ 声库没发声，通常是输出声库路径失效。跑 `/doctor`，或用 `/voices` 重新选一次。

**没有声音**
→ 检查系统音量与默认播放设备；先用 `/playlast` 手动播一次确认。

**切换声库后那行身份信息没变**
→ 切换后都会立刻刷新；如果没变化，输入 `/voices` 看 `*` 是否落在你选的库上。

**Windows 安全中心总弹窗**
→ exe 已带发布者/版本信息（1.2.1.0），但仍属于未签名程序，弹窗属于正常现象。若公司电脑策略允许，可自行用 `signtool` 签名。

**想彻底清理**
→ 关掉程序，删除 `runs\`、`tmp\` 里的内容即可；`config.json` 删掉后下次启动会重新走向导。

## 八、给脚本/程序调用（顺带一提）

```
cevio-NodoAme-talk.exe "こんにちは" --json
{"ok":true,"out":"...","durationSec":2.650,"peak":12343,...}
```

`--json` 会输出单行结果，方便别的程序读。失败的退出码：`7` 空音频、`8` 没有可唱音节、`-99` 超时。

## 九、这版改了什么（最近三版）

- **1.3.1**：全新机器上第一次运行不再暴露任何写死的路径，向导会自己去 CeVIO 安装信息里找安装目录、词典和歌声库。
- **1.3.0**：支持 **Tab 补全**（空行按 Tab 能看到所有命令和说明）、**↑↓ 翻历史**、**Esc 清行**。
- **1.2.2**：切换声库/角色后那行身份信息会立刻刷新；命令打错会提示正确写法。
